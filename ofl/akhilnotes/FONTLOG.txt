FONTLOG for Akhil Notes
-----------------------

This file provides detailed information on the Akhil Notes Font Software.
This information should be distributed along with the Akhil Notes fonts
and any derivative works.


Basic Font Information
----------------------

Akhil Notes is a handwriting family for notes and everyday digital writing.
Designer: Akhil Desai.

Supported glyphsets (glyphsets 1.1.3): GF_Latin_Core, GF_Latin_Plus, GF_Latin_Vietnamese.

Axes: wght 400–900. Italic is a separate family file (not a slant axis on the GF pair).

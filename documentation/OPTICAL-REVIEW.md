# Optical review (P2) — constructed set & stroke weight

Review only. **No geometric cleanup** of provenance handwriting. Do not smooth baselines, symmetrize bowls, or even terminals.

## Scope

Constructed / provisional glyphs that must stay recognizable at text sizes and match Regular→Black stroke weight of the masters:

| Group | Glyphs / notes |
| --- | --- |
| Ligature letters | Æ æ Œ œ |
| Eth / thorn / sharp s | Ð ð Þ þ ẞ ß |
| Barred / stroked | Đ đ Ħ ħ Ł ł Ø ø |
| Currencies | ₦ ₩ ₪ ₫ ₹ ₺ ₿ and kin already in Plus |
| Section / pilcrow / mu | § ¶ µ — § spacing already composite-tuned |

## Checklist (human)

- [ ] Mid-size (16–21px) paragraph: constructed caps don’t look mono-linear vs handwriting.
- [ ] Black (900): stroke weight of Æ/Œ/Ø/ß reads in the same “pen” as D/O/B masters.
- [ ] Italic: same set, slant compatible; no upright-only optical accidents.
- [ ] Currencies: recognizability at 14px; no colliding bars.
- [ ] Fractions / supers / subs (the intentional 38): readable, not redrawn further unless broken.
- [ ] File size: prefer keeping composites; decompose only if paint bugs require it.

## Explicit non-goals

- Mass reverse CCW outers, remove-overlap on original outlines, or AI “cleanup.”
- Mono math widths or glyphsets outside Core / Plus / Vietnamese.
- Contextual alternates invented from rotations (only from real handwriting samples).

# Specimens (designer-authored)

These PNGs are **designer-authored presentation specimens** for the README and
portfolio. They are the official artwork shown on the public repository page.

Do **not** overwrite them with `scripts/make_specimens.py`. That script writes
technical / automated sheets to `output/generated-specimens/` (gitignored) only.

Replace any file here when you have updated art direction — without changing
UFO sources or the build pipeline.

| File | Role |
| --- | --- |
| `01-hero.png` | Hero / brand |
| `02-paragraph.png` | Paragraph texture |
| `03-waterfall-sizes.png` | Size ladder |
| `04-weight-ramp.png` | Weight progression |
| `05-upright-italic.png` | Roman vs italic |
| `06-character-coverage.png` | Character set overview |
| `07-multilingual.png` | Multilingual Latin samples |
| `08-applications.png` | Suggested use contexts |
| `09-kern-liga.png` | Kerning / ligatures |
| `10-interpolation.png` | Intermediate weights |
